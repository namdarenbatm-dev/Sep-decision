# سامانه تصمیم‌یار سپ — PWA

## فایل‌ها
- `index.html` نسخه کامل داشبورد و HTML مستقل
- `manifest.webmanifest` مشخصات PWA
- `sw.js` سرویس‌ورکر برای اجرای آفلاین
- `icon-192.png` و `icon-512.png` آیکن اپ

## اجرا
برای HTML مستقل، `index.html` را مستقیماً در مرورگر باز کنید.
برای PWA واقعی، فایل‌ها را روی HTTPS یا localhost سرو کنید؛ سپس گزینه نصب مرورگر فعال می‌شود.

## داده‌ها
وضعیت تصمیم در `localStorage` نگهداری می‌شود و از داخل اپ امکان پشتیبان‌گیری JSON و بازیابی وجود دارد.
